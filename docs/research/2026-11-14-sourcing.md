## 1. Palettes

### 1.0 Method notes
- ColorBrewer hex: `colorbrewer.js` (axismaps/colorbrewer, export/). CB-safe flags: `colorbrewer_schemes.js` in the same repo, `properties.blind` array (index 0 = 3 classes). Encoding 1 = safe, 2 = doubtful, 0 = not safe (inferred from the data: Spectral/RdYlGn = [2,2,2,0...], RdBu = [1]; confirm on colorbrewer2.org if quoting the legend). `[1]` = safe at every class count.
- CARTOColors hex: `src/carto.ts` in CartoDB/cartocolor v5.0.2 (CC-BY-4.0). Note: Safe and Bold at "5" and "7" classes include a trailing grey "other" colour, so the arrays have 6 and 8 entries.
- viridis/cividis: matplotlib `lib/matplotlib/_cm_listed.py` (256-entry tables). Stops below are the entries at evenly spaced indexes (5 classes: 0, 64, 128, 191, 255; 7 classes: 0, 42, 85, 128, 170, 212, 255), float RGB x 255 rounded. The endpoints equal the well-known official values (#440154/#fde725, #00224e/#fee838); the interior stops are a sampling, not an official discrete scheme.

## 2. Stacks (facts, each with its docs URL)

### 2.1 mapbox-gl / MapLibre GL JS
1. `Map.addControl(control, position)` accepts 'top-left', 'top-right', 'bottom-left', 'bottom-right'; the default is 'top-right' — https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/
2. Controls that choose their own position: AttributionControl 'bottom-right', ScaleControl 'bottom-left', LogoControl 'bottom-left' (`getDefaultPosition()`, source files) — https://github.com/maplibre/maplibre-gl-js/blob/main/src/ui/control/attribution_control.ts (also scale_control.ts, logo_control.ts in the same folder)
3. Map option `attributionControl` takes `false | AttributionControlOptions`. Showing the MapLibre logo is not required — https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/
4. Mapbox needs both its logo and the text attribution. The logo may be moved to another corner but not restyled; text colour and size may be adjusted if still legible — https://docs.mapbox.com/help/dive-deeper/attribution/
5. When using Mapbox data in Leaflet or OpenLayers, those libraries do not add the Mapbox logo/attribution, so add it yourself — https://docs.mapbox.com/help/dive-deeper/attribution/
6. Moving attribution: set `attributionControl: false`, then `map.addControl(new mapboxgl.AttributionControl(), 'top-left')` — https://docs.mapbox.com/mapbox-gl-js/example/attribution-position/
7. Feature-state hover: a paint expression `['boolean', ['feature-state','hover'], false]`; `setFeatureState({source,id},{hover:true})` on `mousemove`; reset it on the previous id and on `mouseleave` — https://docs.mapbox.com/mapbox-gl-js/example/hover-styles/ (MapLibre equivalent: https://maplibre.org/maplibre-gl-js/docs/examples/create-a-hover-effect/)
8. The `feature-state` expression is not supported in layer `filter` expressions — https://maplibre.org/maplibre-style-spec/layers/
9. GeoJSON clustering: `cluster: true`, `clusterRadius` default 50, `clusterMaxZoom` default maxzoom-1, `clusterMinPoints` default 2. Clusters get `cluster`, `cluster_id`, `point_count`, `point_count_abbreviated` — https://maplibre.org/maplibre-style-spec/sources/
10. GeoJSON source `maxzoom` defaults to 18, `buffer` defaults to 128 (range 0-512), `tolerance` defaults to 0.375 — https://maplibre.org/maplibre-style-spec/sources/
11. Large GeoJSON: set the source `maxzoom` below 18 (12 suggested for most point data), remove unused properties, use at most 6-decimal coordinates, cluster at low zoom. Beyond about 500,000 points use further techniques — https://docs.mapbox.com/help/troubleshooting/working-with-large-geojson-data/
12. Layer `minzoom`/`maxzoom` range 0-24. The layer is hidden below minzoom and at or above maxzoom — https://maplibre.org/maplibre-style-spec/layers/
13. `addLayer(layer, beforeId)` and `moveLayer(id, beforeId)` insert beneath `beforeId`; without it the layer goes on top of all others — https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/
14. `raster-opacity` is a paint property, range 0-1, default 1, supports interpolate expressions and is transitionable — https://maplibre.org/maplibre-style-spec/layers/
15. `flyTo` and `easeTo` run instantly when the OS reduced-motion setting is on, unless `essential: true` — https://maplibre.org/maplibre-gl-js/docs/API/classes/Map/ (Mapbox: https://docs.mapbox.com/mapbox-gl-js/api/properties/)
16. FlyToOptions: `curve` default 1.42 (the average from a user study), `speed` 1.2, plus `maxDuration`, `minZoom`, `screenSpeed` — https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/FlyToOptions/ (Mapbox: https://docs.mapbox.com/mapbox-gl-js/api/properties/)
17. The map event map includes `error: ErrorEvent`, so register `map.on('error', ...)` for per-source or per-tile failures — https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapEventType/ (class: https://maplibre.org/maplibre-gl-js/docs/API/classes/ErrorEvent/)
18. GeolocateControl: with `trackUserLocation: false` (default) it is a one-shot button. With `true` it is a toggle with active, passive and disabled states (disabled = unavailable or denied) — https://maplibre.org/maplibre-gl-js/docs/API/classes/GeolocateControl/
19. ScaleControl takes `maxWidth` (example 80) and `unit` 'imperial' or 'metric', changeable with `setUnit()` — https://maplibre.org/maplibre-gl-js/docs/API/classes/ScaleControl/
20. Map option `keyboard` (default true) enables keyboard shortcuts — https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/MapOptions/

### 2.2 Leaflet (stable 1.9.4 reference; the `reference.html` page now documents 2.0.0-beta.4)
1. The map option `keyboard` defaults to true. It makes the map focusable and enables arrow and +/- navigation; `keyboardPanDelta` defaults to 80 px — https://leafletjs.com/reference-1.9.4.html
2. The 2.0 reference adds the `ariaKeyShortcuts` map option so assistive tech can learn the shortcuts — https://leafletjs.com/reference.html
3. Documented keys: Tab/Shift+Tab (map, markers, controls), arrows pan, +/= and -/_ zoom, Shift gives 3x step, Enter/Space on a marker opens its popup, Esc closes a popup or the layers list — https://leafletjs.com/examples/accessibility/
4. Nothing on the map announces the keys, so list them near the map — https://leafletjs.com/examples/accessibility/
5. Marker option `keyboard` (default true): the marker can be tabbed to and activated with Enter — https://leafletjs.com/reference-1.9.4.html
6. Every marker needs a unique `alt` or `title`, which becomes its accessible name. DivIcons need their own label in the HTML — https://leafletjs.com/examples/accessibility/
7. Purely decorative maps should have the HTML `inert` attribute so they are hidden from assistive tech and not focusable — https://leafletjs.com/examples/accessibility/
8. A fullscreen mode is recommended for keyboard, screen-reader and mobile users (`FullscreenControl` in the 2.0 docs) — https://leafletjs.com/examples/accessibility/
9. `zoomControl` and `attributionControl` map options default to true — https://leafletjs.com/reference-1.9.4.html
10. The AttributionControl collects text from layers via `getAttribution`; `addAttribution(text)` adds more, and `setPrefix(false)` removes the prefix — https://leafletjs.com/reference.html
11. Attribution for Mapbox and OSM in Leaflet is done with `addAttribution()` — https://docs.mapbox.com/help/dive-deeper/attribution/
12. markercluster options: `maxClusterRadius` 80 (px), `disableClusteringAtZoom` null, `spiderfyOnMaxZoom` true, `showCoverageOnHover` true (also on keyboard focus), `removeOutsideVisibleBounds` true, `chunkedLoading` false, `animate` true — https://github.com/Leaflet/Leaflet.markercluster/blob/master/README.md (the README now says it supports Leaflet 2.0 and 1.9)
13. The accessibility guide asks you to test with the keyboard alone and with a screen reader — https://leafletjs.com/examples/accessibility/

### 2.3 OpenLayers
1. `ol/control/Attribution`: `collapsible` (if unset, each source decides), `collapsed` defaults to true at startup, `collapseLabel` defaults to '›'. A collapsed-at-start attribution conflicts with the OSMF rule of visibility without interaction, so set `collapsed: false` or accept only the OSMF "collapse after 5 s / interaction" patterns — https://openlayers.org/en/latest/apidoc/module-ol_control_Attribution-Attribution.html (rule: https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)
2. Vector sources have `attributionsCollapsible` default true — https://openlayers.org/en/latest/apidoc/module-ol_source_VectorTile-VectorTile.html
3. `ol/control/defaults` options: `attribution` (true), `rotate` (true), `zoom`, plus `attributionOptions`, `rotateOptions` — https://openlayers.org/en/latest/apidoc/module-ol_control_defaults.html
4. The Rotate control has `autoHide` default true and hides itself when rotation is 0 — https://openlayers.org/en/latest/apidoc/module-ol_control_Rotate-Rotate.html
5. `ol/interaction/defaults` has `keyboard` default true and `zoomDelta` ("zoom delta when using keyboard or double click") — https://openlayers.org/en/latest/apidoc/module-ol_interaction_defaults.html
6. KeyboardPan: arrow keys, `pixelDelta` default 128 px; events attach to the map div unless `keyboardEventTarget` is set — https://openlayers.org/en/latest/apidoc/module-ol_interaction_KeyboardPan-KeyboardPan.html
7. KeyboardZoom: +/- keys, `delta` default 1 — https://openlayers.org/en/latest/apidoc/module-ol_interaction_KeyboardZoom-KeyboardZoom.html
8. Keyboard events attach to the map div by default (`keyboardEventTarget` changes this). OL has an "accessible" example page (HTTP 200); I did not read it, so no focus/tabindex claim is made — https://openlayers.org/en/latest/examples/accessible.html
9. VectorTileLayer: `renderMode` default 'hybrid' (polygons and lines as images, points and text as vectors lifted above them). 'vector' keeps the render order — https://openlayers.org/en/latest/apidoc/module-ol_layer_VectorTile-VectorTileLayer.html
10. VectorTileLayer: `declutter` default false. Layers sharing the same truthy value are decluttered together; `preload` default 0 — https://openlayers.org/en/latest/apidoc/module-ol_layer_VectorTile-VectorTileLayer.html
11. VectorTile source defaults: `tileSize` 512, `maxZoom` 22, `projection` 'EPSG:3857', `overlaps` true, `wrapX` true — https://openlayers.org/en/latest/apidoc/module-ol_source_VectorTile-VectorTile.html
12. WebGL points: `ol/layer/WebGLPoints` takes a literal (JSON) style and is marked `@deprecated, use ol/layer/WebGLVector` in current source. Either layer must be disposed manually or the WebGL context leaks; `disableHitDetection: true` speeds up but turns off hit detection. The apidoc page for WebGLPoints now 404s — https://openlayers.org/en/latest/examples/webgl-points-layer.html and https://openlayers.org/en/latest/examples/webgl-vector-layer.html
13. Layers support `minZoom` (exclusive), `maxZoom` (inclusive), `minResolution`/`maxResolution` and `opacity` — https://openlayers.org/en/latest/apidoc/module-ol_layer_Layer-Layer.html (read from the WebGLPoints options; this exact page was not fetched)
14. Map option `maxTilesLoading` defaults to 16 — https://openlayers.org/en/latest/apidoc/module-ol_Map-Map.html (read from the source option list; this page was not fetched)

### 2.4 deck.gl
1. Picking is opt-in: `pickable` defaults to false per layer — https://deck.gl/docs/developer-guide/interactivity
2. Callbacks: `onHover` fires when the hovered object changes; `onClick` fires on every click on a pickable object. They are set per layer or on Deck, and `getTooltip` renders a default tooltip — https://deck.gl/docs/developer-guide/interactivity
3. Layer props that depend on `pickable`: `autoHighlight`, `highlightColor`, `highlightedObjectIndex` — https://deck.gl/docs/api-reference/core/layer
4. Picking draws pickable layers off-screen while panning and hovering. Limits: 16M items per layer and 256 layers with `pickable: true` — https://deck.gl/docs/developer-guide/performance
5. `updateTriggers` is an object keyed by accessor name whose values are variables that affect the accessor output. Without one the accessor is not re-run when its closure changes — https://deck.gl/docs/api-reference/core/layer
6. A new `data` prop outranks `updateTriggers` and refreshes all attributes — https://deck.gl/docs/api-reference/core/layer
7. Use the `visible` prop instead of conditional rendering to hide a layer — https://deck.gl/docs/api-reference/core/layer
8. Layer `onError` can mark an error handled so it does not bubble to Deck's `onError`. It is the per-layer error hook for a retry state — https://deck.gl/docs/api-reference/core/layer
9. Scale: interactive up to about 1M items; 10-20 FPS near 10M; Chrome's 1 GB allocation limit makes layers crash somewhere between 10M and 100M items; phones are more memory-sensitive — https://deck.gl/docs/developer-guide/performance
10. Pass the same `data` object between renders (shallow compare) or supply `dataComparator` — https://deck.gl/docs/developer-guide/performance
11. Binary data: pass `{src: Float32Array, length: N}` as `data`. Accessors can read `index` and `data` and write into `target` — https://deck.gl/docs/developer-guide/performance
12. External attribute buffers (typed arrays or luma.gl Buffers) can skip CPU attribute generation. Colours sent as floats must be normalised to 0-1 — https://deck.gl/docs/developer-guide/performance
13. GeoJsonLayer accepts a flat binary feature collection (`shape: 'binary-feature-collection'`); `MVTLayer` uses it by default and `geojsonToBinary` converts — https://deck.gl/docs/api-reference/layers/geojson-layer
14. MapboxOverlay (IControl) renders overlaid by default (`interleaved: false`, separate canvas). With `interleaved: true`, layers go into the base map's layer stack and share its WebGL context. Order them with the `beforeId` or `slot` prop. Layers with the same `beforeId` render in batches — https://deck.gl/docs/api-reference/mapbox/mapbox-overlay
15. Interleaved mode: MaskExtension and CollisionFilterExtension only work between layers in the same beforeId/slot group; base-map contexts have `antialias: false`, so PathLayer, LineLayer, ArcLayer and PointCloudLayer look aliased unless you set their antialiasing prop — https://deck.gl/docs/api-reference/mapbox/mapbox-overlay
16. In interleaved mode `useDevicePixels` is ignored, and `getCanvas` returns the base map's canvas — https://deck.gl/docs/api-reference/mapbox/mapbox-overlay
17. Overdraw hurts performance: 5 px scatterplot points cost about 100 pixels each, so 10M points can mean up to about 1 billion fragments — https://deck.gl/docs/developer-guide/performance
